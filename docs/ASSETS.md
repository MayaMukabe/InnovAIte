## Prompt set

Core direction:

> A self-contained isometric floating city district in a polished 3D anime-game style for a friendly K–12 educational adventure; centered square composition, sunny optimistic lighting, no characters, text, logos, watermarks, or UI.

District details:

- Grand Library: books, memory orbs, garden paths; mint, cream, sky blue, gold.
- Engineering Lab: gears, puzzle terraces, turbines, energy cores; cyan, blue, white, gold.
- Knowledge Tower: storybook tower, pages, ribbons; yellow, blue, ivory, coral.
- Art Studio: brush arches, glass roofs, origami gardens; coral, violet, turquoise.
- Research Center: observatories, telescopes, drones, botanical samples; violet, indigo, cyan.
